# Development Environment Setup

Setting up your development environment is the **first step** to becoming a developer.

## What You'll Need

### 1. Code Editor — VS Code

The most popular choice. Download from [code.visualstudio.com](https://code.visualstudio.com).

Features:
- Free and open-source
- Huge extension marketplace
- Built-in terminal
- Git integration

### 2. Node.js & npm

Node.js lets you run JavaScript outside the browser.

**Check if installed:**

```bash
node -v
npm -v
```

### 3. Terminal Basics

Essential commands you'll use daily:

```bash
ls          # List files (Mac/Linux)
dir         # List files (Windows)
cd folder   # Change directory
mkdir name  # Create folder
pwd         # Show current path
```

### 4. VS Code Extensions

Install these essential extensions:

- **Prettier** — Code formatter
- **ESLint** — Code quality
- **GitLens** — Git superpowers
- **Live Server** — Preview HTML

### 5. Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl + backtick | Open terminal |
| Ctrl + P | Quick file open |
| Ctrl + Shift + P | Command palette |
| Ctrl + / | Toggle comment |

## Your First Project

```bash
mkdir my-first-project
cd my-first-project
npm init -y
```

This creates a `package.json` file.

## Pro Tips

1. **Learn the terminal** — it's faster than clicking
2. **Use Git from day one**
3. **Set up a consistent folder structure**
4. **Master keyboard shortcuts**
5. **Install extensions as needed**
